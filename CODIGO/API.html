Descripción General

Sistema de pruebas para validar la estructura, definiciones de test y envío de formularios de entidades de base de datos. Se compone de cinco clases JavaScript organizadas en ficheros independientes.

Estructura de ficheros

CODIGO/ ├── index.html ├── API.html ├── menu_entidades.js ├── Gestor_Class.js ├── TestForm_Class.js ├── TestSubmit_Class.js ├── ValidateFieldsForm_Class.js ├── Validations_Class.js ├── css/IU.css ├── project/ │ ├── project_estructura.js │ ├── project_tests.js ← contiene project_def_tests y project_pruebas │ ├── project_TestSubmit.js │ └── project_Class.js ├── analysis/ │ ├── analysis_preparation_estructura.js │ ├── analysis_preparation_tests.js │ ├── analysis_preparation_TestSubmit.js │ └── analysis_preparation_Class.js └── characteristic/ ├── characteristic_estructura.js ├── characteristic_tests.js ├── characteristic_TestSubmit.js └── characteristic_Class.js

Cada entidad expone cuatro variables globales leídas por Gestor:

nombreentidad_def_testsArraynombreentidad_tests.jsDefiniciones de tests (campo 0–7)
nombreentidad_pruebasArraynombreentidad_tests.jsDatos de prueba (campo 0–6)
nombreentidad_TestSubmitArraynombreentidad_TestSubmit.jsPruebas de submit (campo 0–5)

Formato de def_tests

// [entidad, campo, elemento_html, num_def, descripcion, accion, resultado_esperado, msg_respuesta] const project_def_tests = [ ['project', 'name_project', 'input', 1, 'Campo requerido ADD', 'ADD', 'Campo requerido', 'El nombre es obligatorio'], ['project', 'name_project', 'input', 2, 'Mínimo 15 caracteres ADD', 'ADD', 'Mínimo 15 caracteres requerido', '...'], // ... ];

Formato de pruebas

// [entidad, campo, num_def, num_prueba, accion, [{campo: valor, mimeType?, size?}], resultado_esperado] const project_pruebas = [ ['project', 'name_project', 1, 1, 'ADD', [{name_project: ''}], 'Campo requerido'], ['project', 'name_project', 2, 2, 'ADD', [{name_project: 'abc'}], 'Mínimo 15 caracteres requerido'], ['project', 'name_project', 3, 3, 'ADD', [{name_project: 'Valid Project Name OK'}], true], // ... ];

Formato de TestSubmit

// [entidad, accion, num, descripcion, {campos: valores}, resultado_esperado] const project_TestSubmit = [ ['project', 'ADD', 1, 'Submit ADD completo válido', {name_project: 'Valid Project Name', start_date_project: '01/01/2020', ...}, true], ['project', 'ADD', 2, 'Submit ADD sin nombre', {name_project: '', ...}, 'name_project: Campo requerido'], // ... ];

Validations Validations_Class.js

Clase con métodos estáticos de validación atómica. Todos reciben el id del elemento HTML del DOM y devuelven true si es válido o un string con el mensaje de error.

Métodos estáticos

Static isRequired(elementId)
Validations.isRequired(elementId) → true | string
Valida que el campo no esté vacío (valor.trim() !== '').
ParámetroTipoDescripción
elementIdstringID del elemento HTML

Retorna: true o 'Campo requerido'

Static isInteger(elementId)
Validations.isInteger(elementId) → true | string
Valida que el valor sea solo dígitos (/^\d+$/). Si está vacío, devuelve true.
ParámetroTipoDescripción
elementIdstringID del elemento HTML

Retorna: true o 'Solo se permiten dígitos'

Static hasMinSize(elementId, minSize)
Validations.hasMinSize(elementId, minSize) → true | string
Valida que la longitud del valor sea mayor o igual a minSize.
ParámetroTipoDescripción
elementIdstringID del elemento HTML
minSizenumberLongitud mínima requerida

Retorna: true o 'Mínimo N caracteres requerido'

Static hasMaxSize(elementId, maxSize)
Validations.hasMaxSize(elementId, maxSize) → true | string
Valida que la longitud del valor sea menor o igual a maxSize.
ParámetroTipoDescripción
elementIdstringID del elemento HTML
maxSizenumberLongitud máxima permitida

Retorna: true o 'Máximo N caracteres permitido'

Static noAccents(elementId)
Validations.noAccents(elementId) → true | string
Detecta acentos y ñ mediante expresión regular. Si el campo está vacío devuelve true.

Retorna: true o 'No se permiten acentos o ñ'

Static noSpaces(elementId)
Validations.noSpaces(elementId) → true | string
Detecta cualquier carácter de espacio en blanco (/\s/).

Retorna: true o 'No se permiten espacios'

Static isValidDate(elementId)
Validations.isValidDate(elementId) → true | string
Valida formato DD/MM/YYYY y que la fecha sea real.

Retorna: true, 'Formato debe ser DD/MM/YYYY' o 'Fecha inválida'

Static dateNotBefore(elementId, minYear)
Validations.dateNotBefore(elementId, minYear) → true | string
Valida que el año de la fecha sea mayor o igual a minYear.
ParámetroTipoDescripción
elementIdstringID del elemento HTML
minYearnumberAño mínimo permitido
Static dateNotAfter(elementId, maxYear)
Validations.dateNotAfter(elementId, maxYear) → true | string
Valida que el año de la fecha sea menor o igual a maxYear.
Static isValidFileType(elementId, allowedTypes)
Validations.isValidFileType(elementId, allowedTypes) → true | string
Valida que el MIME type del fichero seleccionado esté en allowedTypes. Si no hay fichero devuelve true.
ParámetroTipoDescripción
elementIdstringID del input type=file
allowedTypesArray<string>Lista de MIME types permitidos
Static validateFileSize(elementId, maxSizeBytes)
Validations.validateFileSize(elementId, maxSizeBytes) → true | string
Valida que el fichero no supere maxSizeBytes bytes.
ParámetroTipoDescripción
elementIdstringID del input type=file
maxSizeBytesnumberTamaño máximo en bytes
Static isValidOption(elementId, validValues)
Validations.isValidOption(elementId, validValues) → true | string
Valida que el valor seleccionado esté en validValues. Si está vacío devuelve true.
ParámetroTipoDescripción
elementIdstringID del select HTML
validValuesArray<string>Lista de valores aceptados
Static executeCustomValidation(elementId, customFunction)
Validations.executeCustomValidation(elementId, customFunction) → true | string
Ejecuta una función de validación personalizada pasada como parámetro.
ParámetroTipoDescripción
elementIdstringID del elemento HTML
customFunctionFunctionFunción que recibe el valor y devuelve true o string de error

TestForm TestForm_Class.js

Clase de tests de atributos. Analiza la estructura de la entidad, valida las definiciones de test y los datos de prueba, ejecuta todas las pruebas y presenta los resultados en una ventana modal con scroll horizontal y vertical.

Constructor

new TestForm(entityName, gestor)
ParámetroTipoDescripción
entityNamestringNombre de la entidad (p.ej. 'project')
gestorGestorInstancia de Gestor que provee estructura, def_tests, pruebas y clase entidad

Métodos públicos

Instance showWindow()
showWindow()
Punto de entrada principal. Llama en orden a analyzeStructure(), analyzeTestDefinitions(), analyzeTestData() y executeAllTests() y pasa los resultados a displayResults().
Instance analyzeStructure()
analyzeStructure() → Object
Verifica que _estructura.attributes sea un objeto no vacío con al menos un atributo.

Retorna:

{ valid: boolean, count: number, attributes: string } // o en caso de error: { valid: false, error: string }
Instance analyzeTestDefinitions()
analyzeTestDefinitions() → Object
Valida que cada entrada de _def_tests sea un array de ≥ 7 campos con los tipos correctos: [string, string, string, number, string, string, true|string]. Cuenta cuántas definiciones hay por atributo.

Retorna:

{ valid: boolean, count: number, wellDefined: number, byAttribute: {fieldName: count}, issues: string[] }
Instance analyzeTestData()
analyzeTestData() → Object
Valida que cada entrada de _pruebas sea un array de 7 campos con los tipos [string, string, number, number, string, Array, true|string]. Contabiliza pruebas de error y de éxito, y agrupa por número de definición de test.

Retorna:

{ valid: boolean, count: number, wellTyped: number, byType: {error: number, success: number}, byDefTest: {defNum: {error, success}}, issues: string[] }
Instance executeAllTests()
executeAllTests() → Object
Itera sobre todas las pruebas llamando a executeIndividualTest(). Compara el resultado obtenido con el esperado y contabiliza aciertos y fallos.

Retorna:

{ executed: number, correct: number, incorrect: number, results: [{pruebaNum, defTestNum, testDescription, fieldName, action, testValue, expectedResult, actualResult, passed, message}] }
Instance executeIndividualTest(prueba, index)
executeIndividualTest(prueba, index) → Object
Ejecuta una prueba individual. Crea un elemento HTML temporal en el DOM, aplica las validaciones de la estructura para la acción indicada (delegando en runValidations()) y compara con el resultado esperado. Distingue entre campos de texto/fecha/select y campos file.
ParámetroTipoDescripción
pruebaArrayEntrada del array _pruebas
indexnumberÍndice de la prueba en el array

Retorna: objeto con pruebaNum, fieldName, passed, message entre otros

Instance runValidations(elementId, validations, isNullable, rawValue, action, fieldName, context)
runValidations(...) → true | string
Aplica en orden las validaciones de la estructura sobre el elemento con elementId: required, integer, min_size, max_size, exp_reg, valid_date y personalized. Si el campo es nullable y está vacío, salta las validaciones de formato.

Retorna: true si todas las validaciones pasan, o el primer mensaje de error encontrado

Instance validateFileValue(rawValue, testObj, validations, isNullable, action)
validateFileValue(...) → true | string
Valida campos de tipo file. Comprueba no_file / campo requerido, type_file (MIME), max_size_file, format_name_file y longitudes de nombre de fichero.
ParámetroTipoDescripción
rawValuestring|nullNombre del fichero
testObjObjectObjeto con mimeType y size
validationsObjectValidaciones de la estructura para esta acción
isNullablebooleanSi el campo es nullable en esta acción
actionstringAcción en curso
Instance displayResults(results)
displayResults(results)
Construye y añade al DOM una ventana modal con cuatro secciones: estructura, definiciones, datos de prueba y resultados de ejecución. Incluye un botón para abrir el detalle de cada prueba en otra ventana modal.
ParámetroTipoDescripción
resultsObject{structure, definitions, data, execution}
Instance showDetailedResults(results)
showDetailedResults(results)
Abre una nueva ventana modal con una tabla que muestra, para cada prueba: número, campo, descripción, acción, resultado esperado, resultado obtenido e indicador visual de éxito/error.

TestSubmit TestSubmit_Class.js

Clase de tests de formulario. Ejecuta pruebas de submit agrupadas por acción (ADD, EDIT, SEARCH, …), validando todos los campos del formulario a través de checkSubmit() y comparando con el resultado esperado.

Constructor

new TestSubmit(entityName, gestor)
ParámetroTipoDescripción
entityNamestringNombre de la entidad
gestorGestorInstancia de Gestor que provee estructura, TestSubmit y clase entidad

Métodos públicos

Instance showWindow()
showWindow()
Punto de entrada principal. Verifica que existan pruebas de submit, llama a analyzeAllActions() y pasa los resultados a displayResults().
Instance analyzeAllActions()
analyzeAllActions() → Object
Determina el conjunto de acciones distintas presentes en _TestSubmit (campo índice 1) y llama a analyzeAction() para cada una.

Retorna: { ACTION: {action, count, correct, incorrect, results} }

Instance analyzeAction(action)
analyzeAction(action) → Object
Filtra las pruebas de _TestSubmit para la acción dada y ejecuta cada una con executeSubmitTest().
ParámetroTipoDescripción
actionstringNombre de la acción: 'ADD', 'EDIT', 'SEARCH', etc.

Retorna: { action, count, correct, incorrect, results }

Instance executeSubmitTest(action, test, index)
executeSubmitTest(action, test, index) → Object
Ejecuta una prueba de submit individual llamando a checkSubmit(action, formData) y comparando el resultado obtenido con el esperado.
ParámetroTipoDescripción
actionstringAcción de la prueba
testArrayEntrada del array _TestSubmit
indexnumberÍndice de la prueba

Retorna:

{ num, description, action, expectedResult, actualResult, shouldHaveError, hasError, correct, message }
Instance checkSubmit(action, formData)
checkSubmit(action, formData) → true | string
Recorre todos los atributos de la estructura. Para cada campo presente en formData, aplica las validaciones correspondientes a la acción normalizada. No realiza la petición al back-end; devuelve todos los errores encontrados o true si todos los campos son válidos. Normaliza acciones: CREATE→ADD, UPDATE→EDIT, READ/DELETE→SEARCH.
ParámetroTipoDescripción
actionstringNombre de la acción (se normaliza internamente)
formDataObjectMapa {fieldName: value} con los valores del formulario

Retorna: true si es válido, o el primer mensaje de error encontrado

Instance displayResults(analyses)
displayResults(analyses)
Muestra una ventana modal con el resumen de pruebas por acción (total, correctas, incorrectas) e incluye un botón para ver el detalle completo.
Instance showDetailedResults(allResults)
showDetailedResults(allResults)
Abre una nueva ventana modal con una tabla por acción que muestra: número de prueba, descripción, resultado esperado, resultado obtenido e indicador visual.

Gestor Gestor_Class.js

Clase de coordinación. Lee las variables globales de la entidad desde window, valida su existencia y las expone mediante getters para que TestForm y TestSubmit puedan consumirlas. También renderiza los botones de test en la zona de trabajo de index.html.

Constructor

new Gestor(entityName)

Invoca validateEntityFiles() inmediatamente. Lanza Error si alguna variable requerida no existe en window.

ParámetroTipoDescripción
entityNamestringNombre de la entidad (p.ej. 'project')

Métodos públicos

Instance validateEntityFiles()
validateEntityFiles()
Comprueba la existencia en window de: nombreentidad_estructura, nombreentidad_def_tests, nombreentidad_pruebas y nombreentidad_TestSubmit. Si alguna falta, lanza un Error con el listado de variables no encontradas. También intenta instanciar la clase de entidad (NombreEntidad) si existe.
Instance loadEntity(workArea)
loadEntity(workArea)
Inyecta en workArea el HTML con los dos botones: Test de Atributos (invoca testAttributesButton()) y Test de Formulario (invoca testFormButton()).
ParámetroTipoDescripción
workAreaHTMLElementContenedor donde mostrar la interfaz
Instance getStructure()
getStructure() → Object
Devuelve el objeto _estructura de la entidad.
Instance getDefTests()
getDefTests() → Array
Devuelve el array _def_tests de la entidad.
Instance getTestsFields()
getTestsFields() → Array
Devuelve el array _pruebas de la entidad.
Instance getTestSubmit()
getTestSubmit() → Array
Devuelve el array _TestSubmit de la entidad.
Instance getEntityClass()
getEntityClass() → Object | null
Devuelve la instancia de la clase de entidad si se pudo instanciar, o null. Usada por TestForm y TestSubmit para invocar validaciones personalizadas (fieldName_personalized_validation()).
Instance validateStructure()
validateStructure() → Object
Verifica que _estructura.attributes sea un objeto con las secciones requeridas (html, db, rules) en cada atributo.

Retorna: { valid, totalAttributes, validAttributes, attributes }

Instance validateDefTests()
validateDefTests() → Object
Valida la estructura del array _def_tests y cuenta entradas por atributo.

Retorna: { valid, totalTests, validTests, testsByAttribute }

Instance validateTests()
validateTests() → Object
Valida la estructura del array _pruebas y contabiliza pruebas de éxito (expectedResult === true) y de error (string).

Retorna: { valid, totalTests, validStructure, successTests, errorTests }

Funciones globales auxiliares

Global testAttributesButton(entityName)
testAttributesButton(entityName)
Crea un Gestor y un TestForm para la entidad indicada y llama a testForm.showWindow(). En caso de error muestra un modal.
Global testFormButton(entityName)
testFormButton(entityName)
Crea un Gestor y un TestSubmit para la entidad indicada y llama a testSubmit.showWindow(). En caso de error muestra un modal.

Validaciones personalizadas en la clase entidad

// nombreentidad_Class.js class Project { // Para end_date_project: debe ser posterior a start_date_project end_date_project_personalized_validation(value, context) { // context es el objeto de la prueba (valoresArr[0]) o formData const startVal = context && context.start_date_project; if (!startVal || !value) return true; // comparar fechas y retornar true o mensaje de error return true; // o 'La fecha de fin debe ser posterior a la de inicio' } }
